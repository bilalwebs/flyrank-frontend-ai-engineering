## Assignment Overview

This document defines the narrative through-line of the React AI Portfolio — the logical thread that connects every section, piece of content, and call-to-action. It maps what a recruiter sees, what they should feel, and what action they should take at each step from first impression to conversion.

## Objective

- Define a single, unifying claim that ties all portfolio content together.
- Map every section's content, featured case, and CTA in a structured table.
- Establish a CTA hierarchy that prioritises the primary conversion (contact) while supporting exploration.
- List the evidence and proof points that must be gathered to make each section credible.
