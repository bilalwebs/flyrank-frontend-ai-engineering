# 6. Final Decision

After comparing all three options, I selected Next.js 16, React 19, TypeScript, and Tailwind CSS because this stack matches both my current skill level and the technologies used throughout the FlyRank Frontend AI Engineering Internship. It provides the best balance between performance, maintainability, scalability, and modern frontend development practices.

### Why?

- Matches the FlyRank Frontend AI Engineering Internship.
- Uses technologies I am actively learning.
- Easy to maintain and expand.
- Supports reusable components.
- Provides excellent performance and SEO.
- Deploys for free on Vercel.
- Can easily support future AI-powered features.

---

# 7. Why I Didn't Choose the Other Options

## HTML/CSS/JavaScript

Although HTML, CSS, and JavaScript are simple and beginner-friendly, they are not the best choice for a portfolio that will continue to grow throughout the internship. Managing multiple pages and reusable UI components would become more difficult over time.

---

## Full-Stack with Database

A full-stack solution with a database would provide more advanced functionality, but my current portfolio does not require authentication or dynamic content. Introducing a backend now would increase project complexity without adding significant value at this stage.

---

# 8. Maintenance

I can confidently maintain this stack because I have already built multiple projects using React and Next.js during my internship. The component-based architecture makes the code easier to organize, maintain, and extend as my portfolio grows.

---

# Final Choice

After evaluating all three options, I selected the following stack:

- Next.js 16 (App Router)
- React 19
- TypeScript
- Tailwind CSS v4
- Vercel for deployment
- No backend at the current stage

This combination provides the best balance between simplicity, scalability, performance, and maintainability while meeting the requirements of both my portfolio and the FlyRank Frontend AI Engineering Internship.
