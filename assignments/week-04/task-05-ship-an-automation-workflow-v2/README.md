## Assignment Overview

This assignment demonstrates how to automate project documentation using AI instead of creating documentation manually.

A reusable AI documentation workflow was designed using **Claude Projects** and **ChatGPT**. The workflow analyzes uploaded project files and generates multiple professional Markdown documents through structured prompts.

The objective was to create a repeatable workflow that improves productivity, reduces manual effort, and maintains consistent documentation quality.

---

## Objectives

- Build a no-code AI documentation workflow
- Generate multiple project documents automatically
- Compare AI-assisted documentation with manual documentation
- Create reusable prompts for future projects
- Document the complete workflow

---

## Workflow

The documentation workflow consists of five main steps:

1. Upload project files to a Claude Project.
2. Claude analyzes the uploaded project.
3. Execute five structured prompts.
4. Review and verify the generated outputs.
5. Save each response as an individual Markdown document.

## Human Review

Although AI generated the documentation automatically, human review was required to verify:

- Technical accuracy
- Markdown formatting
- Project-specific details
- Folder structure
- Technology stack
- Final documentation quality

---

## Known Limitations

- AI depends on uploaded project files.
- AI cannot verify runtime behavior without source code execution.
- Some project-specific details may require manual correction.
- Final review should always be completed before publishing.
