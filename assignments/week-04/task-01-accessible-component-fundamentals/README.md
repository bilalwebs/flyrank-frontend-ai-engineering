
# Accessible Component Fundamentals

This playground contains three accessible React components built from scratch using React, TypeScript and Tailwind CSS.

## Components

- Modal Dialog
- Disclosure
- Tabs

## Accessibility Features

- WAI-ARIA roles
- Keyboard navigation
- Focus trapping
- Focus return
- ARIA labels
- Escape key support
